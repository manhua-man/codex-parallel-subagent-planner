# Request Flow (v0.2.0 中文说明)

本文档展示 `parallel-subagent-planner` (v0.2.0) 作为 **Planner Contract** 在 Codex 请求处理流程中的具体位置与执行步骤。

## 宿主层集成

```text
用户输入
  |
  v
Codex CLI / Desktop 解析请求
  |
  v
Codex 创建或恢复 Agent 会话
  |
  +--> 加载技能 ($HOME/.agents/skills 或 .agents/skills)
  |      |
  |      v
  |   parallel-subagent-planner 加载至上下文
  |
  v
Agent 主循环
  |
  v
LLM 判断技能适用性并执行规划流程
```

## 技能执行流程

```text
用户目标
  |
  v
+--------------------------+
| Scale Gate 分流           |
| 判定 Task 还是 Project?   |
+------------+-------------+
             |
       +-----+------+
       |            |
       v task       v project
+----------------+  +--------------------------+
| Fast split     |  | 发现模块、依赖图与共享契约|
| 快速评估       |  +------------+-------------+
+-------+--------+               |
        |                        v
        |            +--------------------------+
        |            | 分配契约 Owner & Wave    |
        |            +------------+-------------+
        +-------------------------+
                                  |
                                  v
+-------------------------------------------------------+
| Capability & 安全校验 Gate                            |
| - required_capabilities (isolated_context 等)         |
| - model_profile 语义档位 (deep | balanced | fast)     |
| - 预算约束与 Priority launch_score 评分               |
+-------------------------+-----------------------------+
                          |
                          v
+-------------------------------------------------------+
| Planner Contract Schema 确定性校验                    |
| 校验结构化 Plan 是否符合 JSON Schema 及 8 大安全约束  |
+-------------------------+-----------------------------+
                          |
                          v
+-------------------------------------------------------+
| 输出模式渲染                                          |
| - Compact (默认用户视图)                               |
| - Explain (诊断视图)                                  |
| - Machine (标准 JSON 结构化输出)                       |
+-------------------------------------------------------+
```

## 职责划分

- **Codex 宿主**：负责会话管理、工具调度、终端执行、Agent 线程创建与关闭。
- **Planner Skill**：负责规模判定、模块与契约图发现、模型档位分配、预算与优先级评分、Schema 契约校验与三态输出渲染。
